# R Programming Learning Roadmap

#### R Programming Learning Roadmap

এখানে একটি সম্পূর্ণ রোডম্যাপ দেওয়া হলো যা আপনাকে বেসিক থেকে একজন দক্ষ R ব্যবহারকারী হতে সাহায্য করবে।

**মডিউল ১: R এর ভিত্তি স্থাপন (The Foundation)**

* ১.১ পরিচিতি (Introduction): R কী এবং কেন ব্যবহার করা হয়? RStudio-এর ইন্টারফেস পরিচিতি। (আমরা এটি সম্পন্ন করেছি)।
* ১.২ ভ্যারিয়েবল ও ডেটা টাইপ (Variables & Data Types): `numeric`, `character`, `logical` এবং `factor` সম্পর্কে জানা।
* ১.৩ বেসিক অপারেটর (Basic Operators): গাণিতিক (`+`, `-`, `*`, `/`), সম্পর্কীয় (`==`, `>`, `<`) এবং লজিক্যাল (`&`, `|`, `!`) অপারেটর।
* ১.৪ ডেটা স্ট্রাকচার (Core Data Structures): `Vector`, `List`, `Matrix` এবং `Data Frame` তৈরি ও ব্যবহার করা। (আমরা ডেটা ফ্রেমের সাথে পরিচিত হয়েছি)।

**মডিউল ২: ডেটা ম্যানিপুলেশন এবং ক্লিনিং (Data Wrangling)**

* ২.১ ডেটা ইমপোর্ট (Data Import): `readr` প্যাকেজ দিয়ে CSV, Excel এবং অন্যান্য ফাইল থেকে ডেটা লোড করা।
* ২.২ আধুনিক ডেটা ম্যানিপুলেশন (The Tidyverse): `dplyr` প্যাকেজের মাধ্যমে ডেটা নিয়ে কাজ করা।
  * সারি ফিল্টার করা (`filter()`)
  * কলাম নির্বাচন করা (`select()`)
  * নতুন কলাম তৈরি করা (`mutate()`)
  * ডেটা সাজানো (`arrange()`)
  * ডেটা গ্রুপ করে সামারি তৈরি করা (`group_by()`, `summarise()`)
* ২.৩ ডেটা ক্লিনিং (Data Cleaning): `tidyr` প্যাকেজ ব্যবহার করে ডেটা গোছানো এবং অনুপস্থিত মান (Missing Values) নিয়ে কাজ করা।

**মডিউল ৩: প্রোগ্রামিং এর মূল ধারণা (Programming Fundamentals)**

* ৩.১ কন্ট্রোল ফ্লো (Control Flow): শর্তসাপেক্ষে কোড চালানো (`if`, `else`, `ifelse`)।
* ৩.২ লুপ (Loops): একই কাজ বারবার করার জন্য `for` এবং `while` লুপ ব্যবহার করা।
* ৩.৩ ফাংশন লেখা (Writing Functions): নিজের প্রয়োজনমতো ফাংশন তৈরি করে কোডকে মডিউলার এবং পুনঃব্যবহারযোগ্য করা।

**মডিউল ৪: ডেটা ভিজ্যুয়ালাইজেশন (Data Visualization)**

* ৪.১ `ggplot2` এর পরিচিতি: কেন `ggplot2` এত জনপ্রিয় এবং এর মূল ধারণা (layers, aesthetics, geoms)।
* ৪.২ বিভিন্ন ধরনের প্লট তৈরি: বার চার্ট, লাইন চার্ট, স্ক্যাটার প্লট, বক্সপ্লট এবং হিস্টোগ্রাম তৈরি করা।
* ৪.৩ প্লট কাস্টমাইজেশন: টাইটেল, লেবেল, রঙ এবং থিম পরিবর্তন করে আকর্ষণীয় গ্রাফ তৈরি করা।

**মডিউল ৫: পরিসংখ্যান এবং রিপোর্টিং (Statistics & Reporting)**

* ৫.১ বেসিক পরিসংখ্যান: গড় (mean), মিডিয়ান (median), t-test এবং লিনিয়ার রিগ্রেশন (`lm`) এর মতো বেসিক স্ট্যাটিস্টিকাল মডেল চালানো।
* ৫.২ R Markdown: কোড, আউটপুট এবং নিজের লেখা একত্রিত করে সুন্দর রিপোর্ট, প্রেজেন্টেশন বা ড্যাশবোর্ড তৈরি করা।

#### চলুন শুরু করি: ধাপ ৪ - Tidyverse এবং dplyr দিয়ে ডেটা ম্যানেজমেন্ট

রোডম্যাপ অনুযায়ী, আমাদের পরবর্তী গুরুত্বপূর্ণ ধাপ হলো `tidyverse` ইকোসিস্টেমের সাথে পরিচিত হওয়া। ডেটা সায়েন্সের প্রায় সব কাজকে সহজ করার জন্য `tidyverse` হলো কিছু প্যাকেজের একটি অসাধারণ সংগ্রহ। এর মধ্যে `dplyr` সবচেয়ে গুরুত্বপূর্ণ।

**১. Tidyverse ইনস্টল করা**

প্রথমে আপনাকে `tidyverse` প্যাকেজটি ইনস্টল করতে হবে। RStudio এর Console প্যানেলে নিচের কমান্ডটি লিখুন এবং Enter চাপুন:

R

```
install.packages("tidyverse")
```

এটি ইনস্টল হতে কিছুটা সময় নিতে পারে কারণ এটি `dplyr`, `ggplot2`, `readr`-সহ অনেকগুলো প্যাকেজ একসাথে ইনস্টল করবে।

**২. Tidyverse লোড করা**

যেকোনো স্ক্রিপ্টে `tidyverse` এর ফাংশন ব্যবহার করার আগে, আপনাকে লাইব্রেরিটি লোড করতে হবে। আপনার স্ক্রিপ্টের শুরুতে এই লাইনটি লিখুন:

R

```
library(tidyverse)
```

**৩. `dplyr` এর মূল ফাংশনগুলো ব্যবহার করা**

আমরা আমাদের আগের বানানো `students_df` ডেটা ফ্রেমটি আবার ব্যবহার করব। যদি ডেটা ফ্রেমটি আপনার পরিবেশে না থাকে, তবে নিচের কোডটি রান করে আবার তৈরি করে নিন:

R

```
# ছাত্র-ছাত্রীদের তথ্য দিয়ে একটি ডেটা ফ্রেম তৈরি করা
students_df <- data.frame(
  Name = c("Rahim", "Karim", "Sadia", "Mitu"),
  Age = c(22, 23, 21, 24),
  Score = c(85, 92, 88, 95),
  City = c("Dhaka", "Chittagong", "Dhaka", "Khulna")
)
```

এখন `dplyr` এর কিছু অসাধারণ ফাংশন দেখা যাক:

*   `filter()` - সারি ফিল্টার করতে: যাদের স্কোর ৯০ এর বেশি, তাদের তথ্য বের করা যাক।

    R

    ```
    # যাদের স্কোর ৯০ এর বেশি
    filter(students_df, Score > 90)
    ```
*   `arrange()` - ডেটা সাজাতে: স্কোরের উপর ভিত্তি করে ডেটাটিকে বড় থেকে ছোট (descending) ক্রমে সাজাই।

    R

    ```
    # স্কোর অনুযায়ী বড় থেকে ছোট ক্রমে সাজানো
    arrange(students_df, desc(Score))
    ```
*   `select()` - কলাম নির্বাচন করতে: শুধুমাত্র নাম এবং স্কোর কলাম দুটি দেখা যাক।

    R

    ```
    # শুধুমাত্র Name এবং Score কলাম নির্বাচন
    select(students_df, Name, Score)
    ```

**৪. পাইপ অপারেটর (`%>%`) এর শক্তি**

`tidyverse` এর সবচেয়ে শক্তিশালী দিক হলো পাইপ অপারেটর (`%>%`)। এটি একটি ফাংশনের আউটপুটকে পরবর্তী ফাংশনের ইনপুট হিসেবে পাঠিয়ে দেয়। এতে কোড পড়া এবং লেখা অনেক সহজ হয়।

উদাহরণ: ধরুন আমরা এমন ছাত্রদের খুঁজে বের করতে চাই যারা ঢাকা শহরের এবং তাদের স্কোর অনুযায়ী সাজাতে চাই।

পাইপ ছাড়া কোড:

R

```
dhaka_students <- filter(students_df, City == "Dhaka")
sorted_dhaka_students <- arrange(dhaka_students, Score)
print(sorted_dhaka_students)
```

পাইপ (`%>%`) সহ কোড:

R

```
students_df %>%
  filter(City == "Dhaka") %>%
  arrange(Score)
```

দেখুন, দ্বিতীয় কোডটি কতটা পরিষ্কার এবং সহজে বোঝা যাচ্ছে! এর মানে হলো:

1. প্রথমে `students_df` নাও।
2. তারপর (`%>%`) তাকে `filter()` করো Dhaka শহরের জন্য।
3. তারপর (`%>%`) ফলাফলকে `arrange()` করো Score অনুযায়ী।

আপনার কাজ: এখন আপনি চেষ্টা করে দেখুন তো, Chittagong শহরের ছাত্র-ছাত্রীদের মধ্যে যার বয়স সবচেয়ে কম, তাকে কীভাবে এক লাইনের পাইপ কোড দিয়ে খুঁজে বের করা যায়?
